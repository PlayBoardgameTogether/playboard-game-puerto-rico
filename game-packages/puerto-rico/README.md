# 波多黎各上传包

`online.puerto-rico@1.1.0`，经典基础版，3–5 人；支持真人、免费脚本电脑及平台已配置的模型 AI。

```powershell
node scripts/package-puerto-rico.mjs
```

生成 `dist/game-packages/puerto-rico-1.1.0.zip`。管理员在「游戏管理 → 上传游戏 ZIP」检查、审核并上架，之后大厅可创建房间。无需数据库迁移、静态 registry 注册或重启；未安装的环境不会自动出现游戏。ZIP 恰好包含 `game.json`、`server.js`、`client.html`，内嵌原创生成的海港 PNG 图标、封面、背景和物件图集，不使用官方图片。发布新版本，不覆盖历史 1.0.0。

## 范围与规则

包含全部七类角色（按人数放入 0/1/2 张淘金者）、23 种基础建筑、城市 12 格和岛屿 12 格、工人重排、生产供给、贸易、公共船与私人码头、仓储、整轮结束触发与完整计分。

采用经典规则的 75/100/122 胜利点、55/75/95 名供给工人（工人船另放人数个）、工厂 7 金币、大学 8 金币。未采用 1897 版、双人规则、扩展、工厂/大学价格交换或玉米起手少一金币变体。细节见 [游戏指南](../../docs/games/puerto-rico.md) 与包内公开规则。

## 源码与边界

- `shared.txt`：角色、货物和建筑公开目录；打包时同时嵌入服务端和桌面。
- `server.txt`：权威规则、确定性洗牌、私密筹码、身份化 View、合法候选与守恒恢复校验。只能在平台 QuickJS 隔离运行时执行。
- `client.html` / `client.css`：本人 View 的加勒比海港棋桌。手机可切换岛屿/海港，船长阶段默认海港，选船后在船旁确认；电脑并列展示。货物点选后，货船显示合法目标与虚线舱格预览，点击船只后确认，未确认不发送动作。手机工人确认区跟随岗位，避免固定栏被平台导航遮挡。工人岗位和仓储支持自定义，服务器最终校验。土地与城市物件可点击查看图稿与规则详情。
- `art/*.png`：透明徽章、独立封面与横幅、23 种建筑及殖民所/贸易所图稿，以及土地、船只、货物等 16 格物件图集。源图在 `design/artwork/`，生成记录、图集位置和许可见 [美术说明](art/README.md)。打包直接读取有界 PNG，不再依赖 Chromium 渲染同一幅 SVG。
- 动画：以获准的投影事件表现装船、出售、建造、生产和上岗；无 ID、重复、初始化与跳转不触发，连续前进回放按宿主许可表现。新快照、减少动态效果、后台和卸载会清理动画，不阻塞动作。

筹码与完整预估分只向本人展示，终局统一公开；种植园牌堆仅返回数量。事件不携带筹码余额或牌堆顺序。脚本从本人有序候选选择，工人分配提供两种建议，不穷举所有组合；真人可提交任意合法分配。脚本不保证最佳策略。没有平台音效、图包切换或交互教程，也不接入内置游戏专用的个人公开成绩摘要。

正式身份、参与者、控制权、事务、request receipt、revision、恢复与本人回放继续由原平台负责。未提交草稿在身份或权威动作变化后清除；回放只读。真实模型供应商和物理手机的验证范围以开发进度本轮记录为准。
