# 海港美术资源 · 1.1.0

本批画面由 Codex 内置 `imagegen` 根据项目需求生成，再做尺寸、图集对齐与 PNG 编码导出；没有采用商业桌游的扫描件、官方 Logo、第三方图包或网络库存图片。画面用于表达现有经典基础版的物件，不作为历史建筑考证或规则依据。

除另有声明外，按仓库根 LICENSE（GPL-3.0-only）随项目提供。源图与最终提示词保存在游戏仓库的 `design/artwork/`，维护者可审查生成来源。平台集成只引入这里的有界运行图片，不复制大尺寸源图。

| 文件 | 用途 |
| --- | --- |
| `icon.png` | 256×256 透明底海港徽章，独立方形构图；不含白底方框 |
| `cover.png` | 800×450 大厅封面 |
| `harbor.png` | 800×500 详情横幅与棋桌背景，文字侧留出海面 |
| `buildings.png` | 750×750，5×5 建筑图集；依 shared.txt 顺序对应前 23 种建筑，最后两格为殖民所、贸易所 |
| `objects.png` | 704×704，4×4 图集，布局见下表 |
| `cover.svg` | 1.0.0 历史美术源文件保留；1.1.0 的构建不再把同一幅横图缩放进所有展示槽 |

物件图集依次为：第一行玉米、靛蓝、蔗糖、烟草种植园；第二行咖啡种植园、采石场、公共货船、人员船；第三行玉米、靛蓝、蔗糖、烟草货物桶；第四行咖啡桶、金币、木工人、胜利点标记。图集位置只负责美术映射，不参与服务端规则。CSS 用正方形内部精灵保持比例，矩形容器只裁切，不拉伸建筑。

`scripts/export-artwork.py` 使用 Pillow 导出这些已提交的 PNG；正常构建直接读取 PNG，无需 Python、Chromium 绘图或联网生图。输出针对小物件的实际显示尺寸压缩，保留图标透明通道。桌面和 presentation 内嵌图片，仍遵守 PNG 格式、320 KiB 展示图上限、2 MiB ZIP 解压预算及原 sandbox/CSP。
