# 市长工人分配帮助 · D12

沿用海港棋桌 1.1.0 的经典基础版规则与全部物件图稿，不新增美术或重排棋盘。平台指南参考 `PlayBoardgameTogether/PlayBoardgameTogether@1c70c2d` 的 game-experience-guidelines、ui-ux-guidelines、ui-system、ui-development。

目标：玩家手动重排全部工人时，知道为什么不能提交，以及自己的分配能形成什么生产链。服务端合法性、供给、身份与正式动作流程不变；预览只消费本人 View 和未提交草稿。

```text
电脑 / 笔记本
本人行动：规则一句话 → 推荐 / 清空 / 已分配、必须上岗、总工人及岗位
确认区：岗位产能预览（单独一行，供给限制）
        缺少 / 超额 / 待业人数                   [确认行动]
本人岛屿 / 城市：原物件图稿 + 原数值输入，说明关联到人数和预览

手机 390 / 320
原行动提示与推荐 / 清空
原岛屿 / 城市岗位（可触摸、数值输入）
原确认区：未提交产能预览
          人数错误或待业提示     [确认行动]
```

缺少或超额明确给出人数，非法单岗输入给出整数和上限提示。草稿保留原相同快照恢复行为；处理中禁用，提交由原通道确认。玉米仅看上岗种植园，其他作物取种植园与加工岗位的较小值，只解释产能、不承诺未来实际产出。确认区在手机原位跟随岗位，单独换行避免长文挤压按钮；沿用原 Token 和减少动态偏好。
