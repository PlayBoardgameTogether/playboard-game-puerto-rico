# 波多黎各海港棋桌 · 1.1.0 设计

采用现有经典基础版规则；不调整物件数量、价格、隐藏筹码或行动协议。参考 Rio Grande 官方 Deluxe 规则的基础物件布局，不采用其扩展或 126 筹码变体。画面为原创生成，不使用官方卡面或扫描。

主视觉是夕阳下的加勒比海港，区别于原先的文字盒子棋桌。色板：海湾深蓝 `#123c49`、青绿海面 `#277c80`、暖砂岩 `#eddfbd`、陶土 `#a55b3e`、旧木 `#493525`、暖金 `#e8bd70`。展示标题 Georgia/宋体，操作与说明系统无衬线，数量采用等宽数字。已有主题变量继续使用，棋桌样式仅在 iframe 内生效。

船只图稿旁保留真实容量、货物种类、数量和剩余空位；可装载目标直接点选，旁边预览装载数量。船队不能只作为背景。殖民所、贸易所使用独立建筑画面，人员船与货船区分。所有 23 种建筑有自己的图稿，6 种土地、5 种货物、钱币、工人与胜利点有统一资源图稿。核心状态文字仍为 DOM 文本，缺图也可行动。

手机以阶段决定初始区域，用户可随时切换；选择货物、比较船只容量与确认在同一区域完成。原生对话框呈现物件大图与规则，触摸目标不少于 44px，保留键盘和焦点。分配工人沿用数值输入与推荐分配，不强迫拖拽。

实际联机检查发现平台底部导航会遮挡 iframe 内固定确认栏，因此最终采用内容高度模式：手机选船后把同一个确认区移到选中货船旁，工人确认区移到岗位区域之后；不复制动作通道、不硬编码平台导航高度。电脑的确认区留在当前行动面板。

动画只按有 ID 的本人投影事件触发：装货从货物区移向船、建造卡落入城市、上岗与生产短高亮。新权威局面立即呈现，动画不锁住操作。初始化、快照、重复事件、只读跳转不重播；连续前进回放可按宿主 animate 表现；减少动态、隐藏页面及卸载时清理。

美术原图见 `design/artwork/`，导出 PNG 见 `game-packages/puerto-rico/art/`。ZIP 自包含三文件，仍受 2 MiB 解压预算及展示图 320 KiB 单图限制。不会为美术放宽 CSP、媒体格式或安装校验。
